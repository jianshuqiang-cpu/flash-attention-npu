AIC 初始 free→AIV 等待 free→反量化 + 写 L1→双 AIV ready→AIC 读完 L1 → L0→AIC 归还 free

对比重点

搬运位置改变

原：AIC 的 MTE2 直接搬 FP16/BF16 KV 到 L1。

新：AIV 搬 FP8 与 scale，完成 FP32 乘法并 cast 到 Q_T，再写入 L1。

数学主体保留

QK / PV 两个操作数仍是 Q_T；S 与 OTmp 为 FP32，P 与 O 保持浮点语义。V scale 在 PV 前消费。

新增资源与依赖

K/V 共用小条带 scratch，每 AIV 每条带最多 4 token；新增 ready/free 握手，增加 AIV 工作量与 AIC 等待点。
