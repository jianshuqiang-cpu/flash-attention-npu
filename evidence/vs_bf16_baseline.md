# v5 vs 优化前 bf16 算子路径（`csrc/ascend950/flash_attn_npu_3`）对比

## 对照口径

| 列 | 含义 |
|---|---|
| `bf16`（优化前） | 未改动前的算子路径：**bf16 KV + host tiling**，即 PR #466 head `b0e5e56` 的原始行为 |
| `fp8 host` | PR head 的混存 KV（bf16 Q + fp8 KV），仍走 host tiling —— 即本轮"入图"优化前的 fp8 路线 |
| `v5` | 混存 KV + `scheduler_metadata`（AICPU tiling），FD 形态额外经 `prepare_fd_metadata` 静态化 |

同一进程内轮转测量，`wall` = 10 轮中位数（含 host 侧开销），`kern` = profiler Task Duration。
`rel` = v5 与 bf16 同一份输入输出的相对平均误差，即**纯 KV 量化误差**（实现误差另测为 2.1e-3）。

## 结果（device 2，轮转 A/B/C，中位数）

| 场景 | bf16 优化前 wall/kern | fp8 host（入图前） | v5 wall/kern | v5 vs bf16（wall） | v5 vs bf16（kern） | rel |
|---|---|---|---|---|---|---|
| prefill 4096/8192 SWA512 | 0.356 / 0.174 ms | 0.357 / 0.187 | **0.262 / 0.213** | **1.36x** | 0.82x | 3.65e-2 |
| prefill 4096/8192 全注意力 | 1.511 / 1.307 ms | 1.324 / 1.146 | **1.199 / 1.145** | **1.26x** | **1.14x** | 3.80e-2 |
| decode 12x4/8192 SWA512 | 0.196 / 0.014 ms | 0.187 / 0.015 | **0.061 / 0.015** | **3.20x** | 0.90x | 3.71e-2 |
| decode 12x4/131072 SWA512 | 0.203 / 0.013 ms | 0.195 / 0.015 | **0.063 / 0.015** | **3.24x** | 0.89x | 3.65e-2 |
| decode 12x4/32768 全注意力（FD） | 0.458 / 0.284 ms | 0.343 / 0.173 | **0.222 / 0.172** | **2.07x** | **1.65x** | 3.71e-2 |
| decode 12x4/131072 全注意力（FD） | 1.283 / 1.100 ms | 0.808 / 0.627 | **0.680 / 0.627** | **1.89x** | **1.75x** | 3.73e-2 |

## 解读

- **滑窗（step5 生产形态）**：bf16 的 device 时间本来就只有 0.013–0.17 ms，fp8 反量化使它
  略慢（0.82–0.90x）；端到端收益来自**去掉每次约 0.17 ms 的 host tiling**，
  prefill 1.36x、decode 3.2x。
- **全注意力**：fp8 的 KV 带宽优势显现（prefill 1.14x、FD decode 1.65–1.75x kernel），
  叠加 host tiling 去除后端到端 1.26x / 1.89–2.07x。
- 除精度一项（KV 量化 3.7e-2）外，v5 与 host tiling fp8 路径**逐位一致**（含 FD），
  与 bf16 的差异仅来自 KV 量化。

## bf16 路径未改动（回归验证）

用 `b0e5e56` 的独立 worktree 重新编译后测同一批 bf16 用例：

| 场景 | 优化前 worktree bf16 wall/kern | 本包同用例 bf16 wall/kern |
|---|---|---|
| prefill 4096/8192 SWA512 | 0.364 / 0.172 | 0.356 / 0.174 |
| prefill 4096/8192 full | 1.513 / 1.306 | 1.511 / 1.307 |
| decode 12x4/8192 SWA512 | 0.200 / 0.013 | 0.196 / 0.014 |
| decode 12x4/131072 SWA512 | 0.201 / 0.013 | 0.203 / 0.013 |
| decode 12x4/32768 full | 0.465 / 0.285 | 0.458 / 0.284 |
| decode 12x4/131072 full | 1.289 / 1.105 | 1.283 / 1.100 |

差异在 ±3% 噪声内 → bf16 路径无回归（代码上新增参数均为可选，缺省回落到原 tiling 行为）。

## 复现

```bash
python meas_bf16.py <repo>   # 仅 bf16 基线
python meas_v5.py   <repo>   # bf16 / fp8 / v5 对比（本表来源）
```

注：共享机器，跨进程有 ±10% 漂移；本表所有数字来自同一进程内轮转测量。
